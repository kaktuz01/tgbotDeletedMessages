# Бот для сохранения удалённых сообщений

Работает через Telegram Business API (как @ShpayniBot): бот подключается к вашему аккаунту
и видит новые / изменённые / удалённые сообщения в личных чатах.

## Возможности
- Сохраняет всю переписку (текст + фото, видео, голосовые, кружки, стикеры, файлы) в SQLite и на диск
- При удалении сообщения собеседника присылает его копию (с медиа), при редактировании — «было / стало»
- Всё управление кнопками: отправьте боту `/start` (или любое сообщение), появится меню
  - **Чаты** → выбор чата → выгрузка истории txt (последние 100 / вся / только удалённые), игнор чата
  - **Настройки** → уведомления об удалённых и изменённых, уведомления о своих сообщениях, ежедневный бэкап, список игнорируемых чатов
  - **Бэкап сейчас** → файл `.db.gz` с вашими данными (медиа не входят, чужие данные не попадают)
- Кнопка **🆘 Помощь**: как подключить, ограничения и ссылка на автора
- Под каждым уведомлением есть кнопка «Игнорировать этот чат» (игнорируемый чат не сохраняется)
- Ошибки Telegram (лимиты, сеть, заблокированный бот) обрабатываются с повторами и не роняют бота

## Запуск
1. Создайте бота у @BotFather, в его настройках включите **Secretary Mode** (в старых версиях BotFather — Business Mode).
2. `cp .env.example .env` и впишите `BOT_TOKEN`.
3. ```
   python -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   python -m bot
   ```
4. В Telegram (нужен **Premium**): Настройки → Telegram для бизнеса → Чат-боты → выберите бота,
   дайте право читать сообщения.

## Ограничения
- Бот видит только то, что пришло после подключения.
- Боты скачивают файлы до 20 МБ; таймерные (одноразовые) медиа Telegram боту не отдаёт.
- Секретные чаты и группы Business API не поддерживает.

## Деплой
**Docker / VPS:** `cp .env.example .env`, впишите токен, затем `docker compose up -d --build`.
Данные хранятся в `./data`. Логи: `docker compose logs -f`.

**Railway:** New Project → Deploy from GitHub repo → выберите ветку, добавьте переменную `BOT_TOKEN`,
подключите Volume с mount path `/data`. Запускать одновременно локально и на хосте нельзя
(два процесса с одним токеном конфликтуют).

## Платный доступ (Telegram Stars)
- Новому пользователю даётся пробный период (`TRIAL_DAYS`, по умолчанию 3 дня) с момента подключения бота.
- Дальше подписка на `PLAN_DAYS` дней (по умолчанию 30) за `PRICE_STARS` звёзд (по умолчанию 50), оплата кнопкой **💎 Подписка**.
- Без подписки бот продолжает сохранять переписку, но уведомления, выгрузка истории и бэкапы закрыты до оплаты
  (раз в сутки приходит напоминание, если что-то удалили).
- Друзья: на экране подписки кнопка «Я друг автора», запрос приходит админу с кнопками «Одобрить / Отказать».
- Админы задаются в `ADMIN_IDS` (числовые Telegram ID через запятую; свой ID бот показывает на экране подписки).
  У админов безлимитный доступ и кнопка **👑 Админ** (статистика, список друзей, снятие бесплатного доступа).
- `/paysupport` — обязательная для платежей команда поддержки.
- Звёзды поступают на баланс бота (BotFather → бот → баланс / Fragment).
